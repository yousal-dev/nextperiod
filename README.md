# Origins High School Schedule 2025-2026

This is an open-source project of Origins High School Schedule 2025-2026.

Made by an indie developer, for the purpose of making school time management more efficient and easier for students and teachers. Made only for the website [yousal.dev](https://yousal.dev), under the domain of [nextperiod.yousal.dev](https://nextperiod.yousal.dev).

## Features
- View the full weekly schedule at a glance
- Easy-to-use interface for both students and teachers
- Mobile-friendly design
- Open-source: can be adapted or improved by the community
